# dioscRi

Scripts used in the dioscRi manuscript.

## Repository Structure

Each subfolder in `Analysis_files` contains scripts to reproduce specific analyses from the manuscript:

### Analysis Folders
- `BioHEART` - BioHEART study analysis scripts
- `Breast_Cancer_Wagner_2019` - Breast cancer analysis
- `CMV_study_SDY519` - CMV study (SDY519) analysis scripts
- `COVID_19_PBMC_Mathew_2020` - COVID-19 PBMC analysis

## Data Availability

The raw and processed data required for these analyses is available [https://zenodo.org/records/15694581](LINK_TO_DATA).

## Installation

The developmental version of the dioscRi package can be installed from [here](https://github.com/ecool50/dioscRi).

## Usage Notes

**Important:** File paths in the scripts will need to be modified to match your local directory structure before running.
